# Docker

Docker containerizes our application, ensuring it runs consistently across any environment.

## Our Containers
- **FastAPI**: Serves the ingestion and query API.
- **Superset**: The BI dashboard interface.
- **DuckDB/Python**: The execution environment for the ETL scripts.

Using `docker-compose`, a recruiter can spin up the entire ecosystem with one command.
