# DuckDB Basics

DuckDB is an in-process SQL OLAP database management system. It's often called "SQLite for Analytics".

## Why DuckDB?
- **Speed**: Vectorized query execution engine optimized for analytical workloads.
- **Simplicity**: No server to manage, runs entirely within the Python process.
- **Integration**: Natively reads Pandas DataFrames, Polars DataFrames, and Parquet files directly.
